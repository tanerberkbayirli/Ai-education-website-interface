# AI Education Website Interface

A thoughtfully designed template for building a study environment around your own courses and notes.

## Why this project exists

AI can help students turn raw material into useful study notes, but asking AI to build an entire study website often leaves you with an interface that feels generic, inconsistent, or difficult to use. Getting the content might be quick; making the result look polished can require a lot of extra design work.

**AI Education Website Interface is intended to solve that problem.** It gives an AI-assisted study environment a ready-made visual foundation: a coherent layout, color themes, organized subject navigation, and a calm reading space. The goal is for students to focus on their material while the template provides a beautiful interface and adapts the presentation to their notes, without having to design a website from scratch.

This repository is an early local prototype. It already includes the interface and an optional AI-powered note organization backend. Some of the broader study features described below are part of the project vision and are not implemented yet.

## The experience

### A home for every subject

The header displays the student's subjects as a compact navigation. Subjects are loaded from a data file, so the interface is not limited to a fixed set of three courses. Selecting a subject opens its study notes with a subtle transition, keeping the page consistent as the student moves between topics.

The included programming, mathematics, and English courses are sample content. Replace them with your own subjects and actual source material to make the space yours.

### Notes that are easier to study

When configured with an OpenAI API key, the server sends a selected course's source material to the model with built-in instructions. The student does not need to write a separate formatting prompt: the model is asked to organize the material under clear headings, add concise explanations and helpful tips, and use examples where appropriate. Generated text is displayed in consistent cards rather than being allowed to change the page layout.

The result is intended as a starting point for studying, not a guarantee of accuracy. Review generated notes against your source material. Without an API key, the application clearly labels and displays the included sample notes instead of pretending that they were generated by AI.

### A design that stays coherent

The interface includes six selectable color themes, with animated transitions across the page, cards, and accents. Its responsive layout adapts to smaller screens, while reusable visual styles keep the study material ordered and readable.

A break control gives the student a place to pause. A timer is optional; when it finishes, the page displays a message and plays a short alert where browser audio is available.

## Three study templates: the vision

The project is designed around three levels of study support:

1. **Notes only** — a clean digital notebook that brings information together and presents it clearly. The current prototype implements subject navigation and note presentation.
2. **Notes and practice questions** — the same organized notes plus AI-generated questions to help students check their understanding. This is planned, not yet implemented.
3. **Notes, practice questions, and mistake analysis** — a study environment that also records mistakes and uses them for analysis when the student asks. Question generation, mistake storage, and analysis are planned, not yet implemented.

## Run locally

Requires Node.js 18 or later. From this directory, run:

```bash
node server.js
```

Open `http://127.0.0.1:3000`. Opening `index.html` directly does not connect the page to the backend.

### Add subjects and notes

Edit `subjects.json`. Each entry needs a unique `id`, a `name`, source text in `source`, and a `sample` object following the existing examples. The page creates a subject button for each entry. The source text is the material the model organizes; the application cannot infer a student's private notes without a source.

### Enable AI organization

Set the `OPENAI_API_KEY` environment variable on the server before starting it. Optionally set `OPENAI_MODEL` to a model available to your account. The key remains on the server and must not be placed in `subjects.json` or client-side files. When a subject is selected, its source text is sent to OpenAI. Results are cached in server memory until the source changes or the server restarts. API use may incur charges according to your provider account.

For PowerShell, use your own key in the current shell session:

```powershell
$env:OPENAI_API_KEY = 'your-api-key'
node server.js
```

## Project status and limitations

- Local, single-user prototype; no accounts, database, or upload interface.
- The included subject content is illustrative, not a complete curriculum.
- AI organization requires an API key, network access, and a model available to the account.
- AI-generated practice questions and mistake analysis are not implemented.
- The server is intended for local development, not public deployment; authentication and production security are not yet in place.
